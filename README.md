# About Me

I’m a security researcher specialising in **offensive security, exploit development, and systems-level programming**.

My work focuses on building tools and proof-of-concepts that interact with **real-world attack surfaces**, including low-level hardware/software vulnerabilities, network tooling, and cross-platform systems.

---

## Highlight Projects

### Fusée Gelée PoC (CVE-2018-6242)

* Go-based implementation of a BootROM exploit targeting NVIDIA Tegra X1 (Nintendo Switch)
* Built full payload injection workflow with TUI, multi-device support, and JSON config system
* Implemented secure payload handling with SHA-256 verification and automated downloads
* Cross-platform support (Linux, Windows, macOS — amd64 & ARM64)
* Indexed by Vulmon

---

### Chess Engine (Go)

* Bitboard-based board representation for efficient state management
* Iterative deepening with alpha-beta pruning search
* Perft validation for debugging and correctness
* Supports browser UI and UCI protocol for external GUIs
